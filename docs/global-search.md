# 首页全局搜索

首页搜索并行匹配车次、车站、铁路线路、车辆查询、交路、设置、帮助及功能入口。
车次结果显示在列表顶部。车辆记录先返回时，列表顶部保留加载提示；车次返回后，停留在列表顶部即可直接看到车次。
车辆输入使用车辆查询页相同的解析规则，纯数字编号（如 5033）也能检索车辆历史；同一关键词的车次结果与车辆结果同时保留。车辆记录初始展示三条，可展开全部。点击车辆入口保留原始查询词。

设置检索包含子页选项，帮助匹配标题、问题、答案和规则正文。开启车迷工具后，首页搜索才显示线路、车辆、交路结果及车迷工具入口和相关帮助。车迷工具开关仍可通过设置搜索找到。车辆请求独立于车次请求，仅在接口实际返回记录时显示车辆查询区域，加载中、无记录或失败时隐藏车辆区域，保留其他结果。

票价、余票、历史记录等需要起讫站、日期或其他条件的组合查询通过对应功能入口继续填写条件。

## 实机验证

Pixel 8 Pro 和 Pixel Tablet 均通过车辆与交路、线路、入口与帮助三项回归测试。车辆用例使用固定的 G1 车次响应，让车辆记录先返回，确认车次出现后无需向上滚动即可看到。另验证关闭车迷工具时隐藏相关结果，保留 G1 车次，并且仍可搜到车迷工具设置。
