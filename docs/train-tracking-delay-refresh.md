# 车次追踪正晚点同步

在线车次启用正晚点追踪后，服务启动时立即查询，之后每十分钟刷新一次。
页面取得新预测或在同一结果内修改预测时，同步更新追踪时刻、通知和退出期限。
同一车次、日期和查询来源的更新保留会话编号，不重复开启新的追踪会话。

刷新失败或没有有效数据时，保留当天已有预测并继续重试。
到达与出发偏移独立合并，新的零分钟预测覆盖旧晚点值；缺少某个字段不会
清除该字段已有数据。缓存以北京时间日期为界过期，退出期限跟随预计终到时间调整。
关闭正晚点或使用路路通时刻表时，不启动在线正晚点轮询。

新增 `TrainTrackingDelayUpdateTest` 覆盖失败后恢复、部分数据、恢复正点、
空数据重试及跨日过期。
