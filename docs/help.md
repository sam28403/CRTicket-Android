# 帮助中心

首页工具分组按设置、帮助、关于排列。帮助使用原生 Compose Material 3 Expressive，
复用设置标题栏与分组卡片，以及原生导航栈、返回动画、主题和宽屏侧栏。
二级页列出功能，三级页按常见问题和使用规则展示正文。

覆盖车票和历史、车次车站查询、备份恢复与清理存储、到站检测、余票监控与列车追踪、
起售预约、测速轨迹、车辆查询、线路与普速票价、每日小测验、外观与问题反馈。规则来自当前实现，
车次规则以原生与网页当前启用的校验为准，已移除的启动通知不再作为帮助入口。

内容维护在各语言目录的 strings.xml，主题与路由映射在 ui/help/HelpTopics.kt。
本次修订提供简体中文、繁体中文和英文；其余语言目录内的对应条目使用英文。新增功能或变更限制时应同步更新帮助。
