# 车次查询调向标签

时刻卡片右下角仅在 `isTurn === true` 时显示“本站调向”。缺少、损坏或没有匹配的调向数据时，静默省略标签，不增加提示。

数据来自路路通 `extra.dat` 的独立调向站表，不从 `jlb.dat` 交路备注或车次换号推断。解析器先跳过企业字典、附加记录和三组车型分类列表，再读取车次索引、调向站数量和车站索引，双字节数字使用 255 进制。整个调向表校验成功后才应用，避免损坏数据产生部分标签。

离线时按完整车次记录匹配站名；在线时只在完整停站顺序唯一匹配时补入标签，里程缺失不影响调向补全。原生胶囊使用 tertiaryContainer/onTertiaryContainer 成对主题色，叠放在现有底部信息行右下角；停留和里程保留原来的两列位置与宽度，不新增一行或增加卡片高度。

验证：解析用例覆盖正常记录、缺失、截断、非法索引和真实 20261105 数据包的 6856/6857（集宁南、二连）。本地真实包不存在时对应样本测试跳过。

## Pixel 真机验证

Pixel 8 Pro 与 Pixel Tablet 均通过 `TrainTurnStationsDeviceTest`，最终仪器测试分别为 `OK (1 test)`。使用设备实际下载的 20261108 路路通数据查询 6856/6857，验证集宁南、二连有标签，非调向站无标签。

浅色、深色、纯黑模式均检查：胶囊在右下角且位于卡片边界内；与里程不重叠；显示前后卡片高度、里程文字宽度及横向位置一致；主题文字与背景对比度不低于 4.5:1。已核对手机浅色和平板深色截图。未修改设备分辨率或显示密度。

设备截图保存在 CI 包名对应的 `getExternalFilesDir()` 下；构建、安装、仪器测试日志与取回截图位于项目 `logs/turn-stations-*`。
