Android 并不要求默认语言必须为英文；默认 `values/strings.xml` 完整即可。
本项目选择英文回退，因此无需再复制一份 `values-en`。`xml/locales_config.xml`
声明全部支持语言，供 Android 13 及以上的系统“应用语言”设置使用。
原来的 `report_strings.xml` 和 `important_notice.xml` 已合并，资源名称保持有效。

新增文案时使用有含义的资源名称。含变量的句子使用 `%1$s`、`%2$s` 等位置参数，
将完整句子放在一个资源中，避免在代码中拼接句子片段。

- Compose 可直接使用 `stringResource`；需要在事件回调、语义描述或绘制回调中
  读取字符串时，在组合函数中调用 `rememberAppText()`，使用返回的资源访问器。
  它会跟随当前界面的配置变化重新获取资源。
- 持有 `Context` 的代码可使用 `context.getString`。
- 校验、时刻表计算等无界面代码使用 `appString`。应用启动时由
  `TicketApplication` 初始化资源访问器；JVM 测试通过 `StringResourceTest`
  加载简体中文资源，并从默认资源补齐不翻译的公共条目，以保持原有业务测试稳定。
- 枚举及共享标签通过 getter 读取文案，避免类加载时缓存某一种语言。

增加语言时，为该语言建立资源目录并更新 `xml/locales_config.xml`。
每种语言都应包含全部可翻译条目，位置参数的序号与类型必须与默认英文一致。
`translatable="false"` 的品牌、网址等公共资源仅放在默认文件中。
香港和台湾用语分别维护，例如“監察／監控”“電池優化／電池最佳化”。

新增的 22 种语言由 Google 翻译生成完整初稿，再校正车票、积分、日期等关键标签。
它们目前属于待母语审校的译文，不代表已经通过专业语言审校。
特别需要复核老挝语、蒙古语、维吾尔语、藏语的铁路术语与长篇提示。
运行应用不调用翻译服务；译文直接打包为本地 Android 资源。
蒙古语本次采用西里尔字母，不包含传统蒙古文竖排版本。
印度尼西亚语的语言声明使用 `id`，资源目录使用 Android 的旧代码 `values-in`，
避免系统匹配语言时回退到英文。
阿拉伯语、波斯语、乌尔都语、维吾尔语沿用应用已启用的系统 RTL 支持，
不为翻译改变正式组件的布局、尺寸或业务逻辑。

英文“积分”使用 `points`，指铁路会员累积与兑换车票的奖励积分。
车次查询日期标签使用简短的 `Start date`，空状态提示中说明它指列车从第一站出发的日期。
不要为容纳较长译文而调整原有输入框布局。

`LocalizationCatalogTest` 检查条目覆盖、格式参数和语言声明；
`LocalizationResourcesDeviceTest` 验证 Android 实际选择语言、默认英文回退与参数格式化；
`LocalizedHomeDeviceTest` 遍历支持语言，验证首页重组与排版，
不改变设备或应用语言偏好。测试同时读取实际语言声明，避免增加语言后遗漏设备校验。

本次范围仅为 Android 原生代码与资源。Web 源码和资源未修改；车站名、地理名称、
接口字段与状态值、席别等持久化值、日期存储格式和解析规则保持原样。
Web 返回的提示及数据标签也保持原样，完整国际化时需要单独处理这些来源。
本地化只替换显示文案，不调整原有页面布局、组件样式、导航或业务规则。
语言预览使用的容器仅存在于设备测试中，不改变正式界面。

## 应用内语言选择

从首页进入“设置 → 语言”三级页面，可选择上述 26 种语言或“跟随系统”。
页面使用 Compose 和现有 Material 3 Expressive 设置样式，单选后立即应用。
语言列表直接读取 `locales_config.xml`，各语言使用资源中的本地名称展示，
不会因切换语言而无法辨认原来的语言名称。

选择通过 `AppCompatDelegate.setApplicationLocales` 设置；“跟随系统”传入空列表。
Android 13 及以上与系统的应用语言设置保持同步；较早版本由 AppCompat 自动保存。
Activity 使用 AppCompat 的无操作栏宿主主题，界面仍由原有 Compose 主题绘制。
非界面 `appString` 通过 `ContextCompat.getContextForLanguage` 读取语言资源。
切换时保留原有导航状态，不修改 Web 源码、账户数据或业务数据。

`LanguageSettingsDeviceTest` 验证设置入口、语言切换、Activity 重建、返回层级、
RTL 和恢复系统默认，并在结束时恢复设备原来的应用语言偏好。
