# 车辆查询（第一版）

- 入口：铁迷工具 → 车辆查询，原生 Compose 页面。
- 输入会去除首尾空白并转为大写。与 rail.re 一致，`^0?[GDC]\d{1,4}$`
  使用 `/train/` 查询，其余 `^[-+\w@]+$` 输入使用 `/emu/` 查询。
  支持 `380B-3626` 完整车号及 `1E`、`BF5` 等片段，不在此页提供车站查询。
- API：`https://api.rail.re/train/{keyword}` 和
  `https://api.rail.re/emu/{keyword}`。展示接口返回的全部记录，按日期倒序分组，
  同一天按时间倒序排列；不将重复担当同一车次的不同日期记录合并。
- 接口目前有返回数量限制，无分页参数；界面不能承诺覆盖车辆整个服役期。
- 卡片布局沿用到访车站统计的日期标题、16 dp 边距、8 dp 间距和自适应列宽。
  历史车次直接复用完整车次列表卡片，通过同一摘要函数获取对应日期的路路通数据，
  展示始终到站、停站数、历时、里程和均速；对应日期无记录时使用不可用占位。
- 车号卡片左侧展示源车号，右侧展示对应车型车头图，点击继续查该车号。
  车型对应表来自 https://www.china-emu.cn/Trains/ALL/ ，2026-10-21 提取，
  存于 `app/src/main/assets/vehicle-model-images.json`，图片从该网站按需加载。
  优先使用明确车号／闭合号段匹配的版本，再回退到车型默认图片。
  涉及改号、改造或缺少明确号段的条目保留默认版本；无图时不显示额外说明文字。
- 新查询取消旧请求，离开页面取消请求；支持加载状态、空结果、失败重试及输入校验。
- 搜索历史仅存于本机，按最近使用顺序去重保留 10 条，支持带动画的一键清空。
  搜索框的关闭按钮取消请求并重置结果，回到搜索历史和车头轮播初始界面。
- 轮播支持手动滑动，每 4 秒自动切换；页面未激活或 Activity 暂停时停止自动播放。
- 轮播覆盖车型目录 2026-10-21 快照的全部 307 个条目，包含样车、变体及市域车型；
  原站没有车头图片的条目保留车型名称，回退到默认图片或默认图标。
  图片仅加载当前及相邻页面，共享最多 32 张图片的缓存，不同时下载全目录。
  使用 `tools/update-vehicle-carousel.ps1` 更新目录；脚本校验页面卡片数与提取数一致。
- 车次卡片中的车号胶囊：CR400AF、CR300AF 为红色；CR400BF、CR300BF 为橙色；
  CR200 为绿色；CRH1 为黑色；CRH380A 及其他为蓝色。点击胶囊查询该卡片车次的历史用车，
  点击卡片其余区域仍打开该日期的车次详情。
- 图片别名：CR200J 使用 CR200J1-A 图片，CR200JB 使用 CR200J1-B 图片，
  CR200JC 使用 CR200J1-C 图片，CR200JD 使用 CR200J1-D 图片。
- 特别涂装精确按完整车号匹配，优先于系列：CR400BFZ0524 使用紫色胶囊及亚运版车头图，
  CR400BFC5162 使用天蓝色胶囊及冬奥版车头图；输入中的连字符不影响匹配。
  两种特别涂装分别使用独立图片键，避免与普通 CR400BF-Z / CR400BF-C 共用错误的缓存结果。
- 应用界面不显示数据来源说明，集中在 README 和本说明维护。
- 开启车迷工具后，首页搜索仅对 G、D、C、S 开头且符合完整车次规则的输入提供“搜索XX配车”入口，
  并显示该车次最新的一条担当车辆记录，复用车辆查询卡片；关闭开关或输入不完整时不显示。
  配车加载失败时隐藏配车入口、车辆卡片及相关提示，保留其他搜索结果。
  先完成当前关键词的车次搜索，再显示配车入口并请求配车；车次加载失败时不请求配车。
  输入完整车号（如 `CRH380B3626`、`380B-3626`）时，同样在车次搜索完成后查询历史，
  仅展示最新的一张历史车次卡片，与车辆查询共用组件；可进入该车号的完整查询结果。
  入口携带 `train` 参数直接查询车次，不改变原有车号片段查询规则。
- 车辆查询支持下拉刷新已提交的查询，保留当前卡片与滚动位置。
  初始搜索历史界面不发起刷新，刷新不重复添加搜索历史；刷新失败时保留已有结果并允许重试。
- 车型详情的逐项核对结果和新增规则见 [图片核对清单](vehicle-artwork-audit.md)。
- 第一版提供英文默认文案及简体中文，其他语言暂使用英文回退。
