# 备份版本兼容

新导出的完整备份通过 `appVersion` 保存软件版本，`schemaVersion` 仍表示数据格式版本，两者独立维护。Android 使用安装包版本，网页构建读取 `gradle.properties` 的 `crticket.version`。

恢复时先执行现有格式、设置及 Android 原生设置校验，再写入数据。来源版本高于当前版本时，校验通过则正常恢复并提示尽快更新；校验失败则要求更新后再导入。未知数据格式版本也要求更新。运行时存储失败仍报告原有错误，不归类为版本不兼容。

没有软件版本信息的历史数组、旧版备份及网页备份保留原有导入路径。低版本备份导入高版本不会增加更新提示。加密备份解密后按相同规则处理。

## 验证

- 网页侧 `npm run test:android`：262 项通过。
- CI 应用及测试 APK 构建通过。
- Pixel 8 Pro：版本兼容性用例单独重跑通过，两项加密备份用例通过。组合运行首个用例曾因启动界面未就绪超时，不作为整组通过记录。
- Pixel Tablet：版本兼容性用例通过。
- 版本用例覆盖导出版本号、高版本兼容提示、网页设置及 Android 原生设置不兼容时阻止写入、无版本网页备份和低版本备份恢复。未知格式版本由网页单元测试覆盖。
- 构建、安装和测试日志保存在 `logs/backup-version-*`。
