# 欢迎页与本次更新

首页左上角的应用图标和 CRTicket 标题共用点击区域，点击后直接打开
Welcome Screen 的“本次更新”页，展示当前版本打包的 Markdown 更新日志。
“本次更新”标题使用项目内置的 Google Sans Rounded。

从首页打开时，底部按钮和系统返回键均关闭更新页，返回已有首页，保留其状态。
此入口不修改首次使用条款或版本确认记录。首次安装和升级时的欢迎流程保持独立。

设备回归测试位于 ExpressiveHomeTest 的
homeTitleOpensReleaseNotesAndReturnsToTheSameHome，覆盖打开、按钮返回与系统返回。

## 版本数值与更新完成

关于页和更新欢迎页使用 `VERSION_NAME (VERSION_CODE)` 展示完整版本。
日志文件仍以语义版本命名，例如 `0.9.4.md`。

启动时分别检查条款版本和 `welcome.versionCode`。
只要版本数值与上次完成欢迎流程时记录的数值不同，就展示更新完成欢迎页，
即使语义版本相同也会展示；降级同样适用。
旧安装只有语义版本阅读记录时，首次接入后展示一次更新欢迎页。
完成流程才写入当前数值，退出或只从首页查看更新日志不改变该记录。
首次使用和条款变更继续走条款确认流程。

## 大屏布局

可用宽度达到 840 dp 时，欢迎首页使用左右分栏，图形与文字并排显示；
其余尺寸维持纵向布局。大屏内容区域限制最大宽高，底部增加系统任务栏避让空间。
欢迎正文可滚动，下一步和完成操作位于正文滚动区域之外。
