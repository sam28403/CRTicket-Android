# 搜索与车次查询导航

搜索按时刻表车次记录进行不区分大小写的包含匹配，不限制车次字头。
X、N、V 字头均可搜索，支持仅输入字头、部分车次及完整车次。
未来时刻表包含 X 字头记录后，无需修改搜索规则即可展示；无对应数据时结果为空。
`globalSearch.test.js` 使用模拟时刻表验证列表生成到搜索匹配的完整数据链路，
包括 X 双车次记录。此验证不代表当前真实时刻表已有 X 字头车次。

搜索结果匹配与详情页车次校验独立。当前详情页接受已启用的 N、V 号段，
X 号段规则仍未启用，因此 X 搜索结果进入详情后的查询仍会被校验拦截。

搜索结果复用车次列表的 MD2 快速滑动条。进入结果详情后返回，保留关键词、
分组展开状态、已完成的搜索结果和列表滚动位置，不重新发起搜索请求。
关键词发生变化时清空旧结果并回到列表顶部；未完成的请求仍按请求编号隔离。
车组配属搜索已完成的结果也在当前搜索会话内保留。

车次列表、车站大屏、交路预览、车组历史和搜索结果进入车次查询时均先查询在线来源。
双车次和方案后缀在在线请求前转换为可查询的单车次，完整记录号保留给离线回退。
在线异常、无停站数据或接口返回离线备用结果时，继续使用已有的路路通回退流程。
查询页手动切换来源仍然有效。

回归测试包括 `GlobalSearchTest` 的请求次数、展开状态和返回位置断言，
以及 `TrainQueryOnlineEntryTest` 的在线优先和完整离线记录号回退断言。
