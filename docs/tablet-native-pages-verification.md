# Pixel Tablet 原生页面布局验证

2026-10-15，Pixel Tablet，设备原有 320dpi，未修改分辨率、密度及字体缩放。

## 修改

- 车次列表复用设置的 `ExpressiveNavigationShell`：宽屏左侧约三分之一为导航，
  右侧为列表，选中“车次列表”；书本式折叠按折痕左右分区，桌面式折叠上下分区。
- 窄屏恢复单栏。列表状态提升到分栏外部，旋转及布局切换保留滚动位置；切换日期回到顶部。
- 车次列表的原生快速滚动条继续使用实际列表的范围和位置，不扩展到导航区域。
- 到站检测三级页面移除顶部“接受到访车站的通知”；设置二级菜单中的说明保留。
- 到站检测插图按可用高度限制大小，避免横向折叠时把启用开关挤出首屏。

## 设备验证

`:app:assembleDebug`、`:app:assembleDebugAndroidTest`、`:app:lintDebug --offline` 通过。
`TabletNativePagesTest` 两项测试通过，耗时 29.711 秒。

- 普通平板、书本式折叠、桌面式折叠均检查导航分栏、内容不跨折痕、日期与总趟数、
  列表只有纵向滚动、跳至第 8,001 条及组合条目少于 30 个。
- 到站检测在上述姿态中检查二级说明保留、三级说明不存在、开关显示及权限入口可滚动到达。
- 横竖屏切换检查列表位置保留、到站检测开关显示；测试结束恢复原有旋转配置。
- 折叠姿态使用 AndroidX Window 测试库在真实 Tablet 上注入 32px 折痕，
  并非实体折叠屏铰链／传感器测试。

初轮直播画中画遮挡内容；用户关闭后完成验证。基座未妨碍横竖屏测试，无需移除。
未更改到站检测开关或权限；设备现有业务记录保持原状。
