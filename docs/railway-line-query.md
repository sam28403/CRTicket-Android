# 线路查询

入口位于首页车迷工具，使用原生二级页面 `/railfan/lines`，支持手机和宽屏详情区域。

## 数据范围与来源

- 数据来自[黄河铁路网车站信息查询](https://www.jprailfan.com/tools/stat/index.php)。应用接入该来源的完整线路目录，并非全国铁路官方完整清单。
- 内置 `app/src/main/assets/railway-lines.json` 为 2026-10-26 读取的 759 条线路名称，包含普速、高速、城际、支线和联络线。进入页面后尝试更新目录，无网络时保留内置目录。
- 输入名称后按包含关系筛选全部候选，不截断结果。选择线路后按需请求该线路的站点表，不批量抓取全站。
- 展示源表的“距起始站里程”，不是相邻站间距、地图测量距离或列车实际运行里程。起点随线路定义变化，例如京广线以北京丰台为 0 km。
- 保留源表顺序及所列线路所等节点，不擅自补站或推算缺失里程。缺失里程显示破折号，页面不添加“站”后缀。
- 单条线路和目录缓存 24 小时，过期后尝试更新，更新失败时可使用已有缓存。Android 清理缓存后，未缓存线路需联网查询。
- 来源是第三方资料，线路范围、改名和里程可能滞后，不能视作实时官方运营数据。上游页面结构变化时显示加载失败并允许重试，不生成模拟数据。

## 抽查

2026-10-26 对京沪线、京广线、京哈线、京港高速线商合段、沪昆高速线及阿阿线抽查解析。
截图对应京港高速线商合段：商丘东 16 km、芦庙 49 km、亳州南 76 km、古城东 106 km、太和东 149 km，均与源表一致。

## 布局与验证

标题栏、返回按钮、搜索框圆角和明暗主题沿用现有车迷工具页面。候选菜单跟随输入框，站点图使用主题色双线及空心圆，里程与 km 不换行。
站名和里程使用 22 sp 字号。结果卡片可用宽度达到 600 dp 时切换蛇形图，按宽度及字体缩放分为 2 至 6 列，奇偶行反向排列并在行边连接。宽度不足时保留纵向线路图。
单元测试覆盖目录提取、候选搜索、累计里程列、千位分隔符、缺失值、跨线路过滤及截图站点样本。

2026-10-26 首版验证结果：137 项单元测试通过，debug 构建通过，lint 为 0 错误（152 条警告、9 条提示）。
Pixel 8 Pro（Android 17）上通过实际导航、候选选择、联网加载、滚动定位及无匹配结果测试，并检查浅色和深色页面。
实机测试使用独立 `cc.samlab.ticket.ci` 包；未对全部 759 条线路逐条核对数据。
字号与蛇形图更新通过手机布局及宽屏布局两项设备测试。宽屏测试在 Pixel 8 Pro 上临时设置 2400×1600、240 dpi，检查跨行连接及最后一行不足整行时的排列，测试结束恢复原尺寸及密度；未使用实体平板测试，也尚未验证大字体设置。
后续宽屏设备测试仅在已连接的真实平板上运行，手机自动跳过；不再修改手机的分辨率、显示密度或模拟平板布局。Pixel 启动器切换平板布局可能造成桌面图标丢失，恢复显示配置不能避免该影响。
