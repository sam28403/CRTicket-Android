# 到访提醒 Android 模拟位置验证

日期：2026-10-11。设备：用户的 Pixel 8 Pro，Android API 37。
原项目同步版本：`0b926b1`。

使用 Google Play 服务 Fused Location Provider 的 `setMockMode` / `setMockLocation`。
测试向系统注入精度 5 米、带当前时间的 WGS84 位置，等待生产定位订阅或地理围栏接收器
发布真实 Android 通知，不直接调用通知发布函数，不伪造围栏广播。
每站先在站点正北 400 米处启动监控并等待围栏注册，再移至正北 250 米处。
通知跳转通过实际通知的 PendingIntent 验证 WebView 对应站名的车站大屏路由。

测试结束关闭 FLP 模拟模式，恢复原有提醒设置和通知冷却记录，模拟位置 AppOps 恢复为 deny。
不修改车票或用户数据库。模拟权限只声明在 debug manifest，release manifest 不含该权限。

本次验证为模拟位置实机测试，不是电量基准测试，也未模拟整条跨地区旅行路线。
正式逻辑使用系统进入围栏和约 5 分钟的平衡功耗定位，没有测试专用的高频定位订阅。
实际系统省电或后台限频仍可能使通知延迟；大屏数据能否取得取决于上游是否收录该站。
