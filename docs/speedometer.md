# 车速表初版

- 首页「车迷工具 → 车速表」：配置车次与起终点，自由填写站名，支持站名、拼音和首字母推荐。
- 再次确认前显示摆放动画、CR200J 车窗铁丝网说明和信号中断处理说明。
- 实时仪表盘固定纯黑背景，浅色刻度、数字与操作按钮；速度单位为 km/h。
- 信号中断后从绿色平滑切换至偏红色，恢复信号后回到绿色；背景始终保持纯黑。
- 起终点只要求填写，允许同站；轨迹顶部复用车次列表标准卡片，移除下方说明文字。
- 使用系统 GPS，每秒请求定位，丢弃过期定位、精度差于 50 米的定位及明显异常的短时跳点。
- 信号超过 10 秒未更新时隐藏速度，保留计时。恢复后按直线连接前后定位并累计里程。
- 暂停冻结计时和里程；恢复时开启新轨迹段，暂停期间的移动不补算。
- 均速为累计里程除以未暂停的记录时间，包含停车和信号中断期间的时间。
- 使用 location 类型前台服务，切换应用和熄屏后仍可继续记录。系统可能限制 GPS 采样。
- 停止后保存真实统计数据和轨迹，历史卡片使用车次列表组件，不显示站数胶囊。
- 轨迹页使用本地打包的 Leaflet 和 OpenStreetMap 标准底图，支持缩放、拖动和归属标注。
- 底图需要网络；加载失败时仍展示本地轨迹，并显示提示。
- 数据保存在应用私有目录 `speedometer.json`，原子写入，每 10 秒保存一次活动记录。
  进程意外终止后，下次进入将最近一次保存的活动记录作为历史展示，不自动补计终止后的时间。
- 初版提供简体中文、繁体中文和英文文案，其他应用语言的新增测速文案暂使用英文。

## 表盘量程

| 车次 | 最大速度 km/h |
| --- | ---: |
| G | 350 |
| D | 250 |
| C1–C1000、C4001–C4700 | 160 |
| 其他 C | 350 |
| S | 200 |
| Z | 160 |
| T | 140 |
| K、Y、L、数字车次 | 120 |

量程只约束圆弧显示，实测速度数字不会因超出量程而截断。

## 验证

`SpeedRecordingTest` 覆盖量程边界、信号中断直线补算、暂停分段、过期定位和计时格式。
`SpeedometerDeviceTest` 检查配置校验、自定义站名、引导、全黑测速界面、信号中断、历史轨迹入口，
并通过实际前台服务验证暂停、继续和停止保存。设备测试中的展示数据为测试夹具，不会写入正式历史。
实际列车上的 GPS 精度与隧道信号恢复效果仍需实乘验证。

底图接入遵循 [OpenStreetMap 瓦片政策](https://operations.osmfoundation.org/policies/tiles/)，
定位服务声明参照 [Android 定位权限文档](https://developer.android.com/develop/sensors-and-location/location/permissions)。

## 车号、历史管理与设备支持

- 起点站和终点站并排填写，下方车号为选填，随记录保存；旧记录默认无车号。
- 历史和轨迹页卡片右上角显示车号胶囊，复用车号查询配色。
  YW、RW、YZ、RZ、SYW、SYZ、SRW 前缀使用橄榄绿色。
- 历史记录支持左滑删除，底部显示「已删除」和「撤销」操作，后续记录平滑上移。
  撤销恢复完整轨迹并重新保存。连续删除时，提示对应最近一次删除。
- 首页依据系统 FEATURE_LOCATION_GPS 硬件特性显示车速表。
  仅支持网络或蓝牙定位的设备隐藏入口；设备暂时关闭定位不会隐藏入口。

- 记录的未暂停时间不足 60 秒时不计入历史；恰好 60 秒可以保存。进程恢复时同样过滤不足 60 秒的记录。

## 空历史与实时布局

- 历史为空时显示与应用一致的动态图形空状态。
- 实时车速表不使用纵向滚动容器。竖屏上下排列，横屏左右排列。
- 表盘根据可用空间等比例缩放；紧凑高度使用更小的统计区间距，保留暂停与停止操作。
