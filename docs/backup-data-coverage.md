# 本机备份数据范围

检查日期：2026-10-23。入口为设置页的导入备份、导出备份，格式仍为兼容旧版的 JSON schemaVersion 2。

## 选择备份内容

导出时选择内容后再选择保存位置，导入时选择文件后再选择恢复内容。两者均支持多选，
每次打开默认全选，至少选择一项才能继续。导入仅列出文件实际包含的类别。

| 类别 | 内容 |
| --- | --- |
| 车票历史记录 | 已保存车票及创建时间 |
| 搜索记录 | 车次、车站、车辆和起售时间查询历史 |
| 设置项 | 外观、语言、重要通知、到站检测、车迷工具、起售提醒方式及同城开关 |
| 个人资料 | 用户名和头像 |
| 到访车站记录 | 到访车站、首次到访时间及历史标记 |
| 测速记录与轨迹 | 测速历史、GPS 轨迹及暂停分段 |
| 车票生成草稿 | 原生表单及 WebView 的持久化草稿 |
| 余票监控配置 | 监控条件，恢复后不自动启动任务 |

未选择的内容不会写入导出文件，导入时也不会覆盖本机相应数据。
选择性备份在 schemaVersion 2 中增加 `contents` 类别列表，车票未选时仍保留空 `tickets` 数组，
以便旧版读取。旧版车票备份只提供车票类别；没有 `contents` 的完整备份根据实际字段识别类别。
资料未选时，兼容字段 `user` 为 `null`，避免从文件头部带出用户名。

| 数据 | 存储位置 | 导入导出 |
| --- | --- | --- |
| 已保存车票及创建时间 | WebView 本机存储 | 已支持，合并并跳过重复车票 |
| 用户名、头像 | WebView 本机资料 | 已支持 |
| 外观、语言、重要通知偏好 | WebView 及 Android 设置 | 已支持 |
| 到站检测偏好、到访车站与历史标记 | Android station-arrival | 已支持，保留较早到访时间 |
| 车迷工具开关、车辆查询历史 | Android 设置 | 已支持 |
| 车次、车站查询历史 | WebView 本机存储 | 已支持 |
| 余票监控配置 | Android ticket-monitor | 已支持，导入不启动任务 |
| 车速记录及 GPS 轨迹 | Android speedometer.json | 本次补齐，包含统计、车号、坐标及暂停分段 |
| 车票生成草稿 | Android ticket-generator 及 WebView 本机存储 | 本次补齐，允许未填写完整的表单 |

## 合并与兼容

- 轨迹保留原记录 ID，按 ID 去重并与现有记录合并，同 ID 保留本机版本。
- 正在测速且已满 60 秒的记录可导出当前快照；导入仅增加历史，不覆盖或恢复活动定位任务。
- 不足 60 秒的记录不进入备份；旧版备份不含轨迹或草稿字段时，不更改这些本机数据。
- 显式的空草稿会清除草稿；恢复草稿时清除旧的待导出回执，避免将恢复后的内容关联到旧保存操作。
- 本机车票草稿与 WebView 草稿同步，重新进入生成器时刷新原生表单。
- JSON 单文件继续限制为 20 MB；native bridge 的原 2 MB 文本上限已提高到 20 MB，
  避免较大的轨迹备份在选择文件后被较小的桥接上限拒绝。
- 轨迹校验拒绝错误坐标、非递增时间、倒退分段、无效时长及重复 ID，不静默截断。
- 轨迹通过单一写入队列和 AtomicFile 提交，确认写入成功后更新界面状态。
  轨迹提交失败会回滚本次原生偏好写入，并由 Web 层回滚车票、资料及本机存储。

## 不迁移的数据

系统授权、通知渠道、通知冷却信息、缓存数据版本、接口查询缓存、正在运行的列车追踪与余票监控会话、
临时页面输入和待导出回执属于设备环境或运行状态，不作为用户记录迁移。
车票生成草稿是持久化的未完成内容，已单独纳入备份。

## 起售提醒与恢复后的权限检查（2026-10-23）

起售提醒方式和同城开关以 `saleAlarmEnabled`、`saleSameCity` 纳入“设置项”，起售查询历史以 `saleSearchHistory` 纳入“搜索记录”。Android 和网页两侧都校验类型及历史长度，再执行现有事务写入；只导入某个类别不会改动另一个类别。旧备份没有这些字段时保留本机原值。返回起售查询页时重新读取持久化设置和历史，避免导航缓存覆盖恢复值。

当天预约、已投递标记、精确闹钟 PendingIntent 和正在响铃的服务属于一次性运行状态，不导出，也不通过恢复备份重新预约。系统权限和通知渠道同样不能从备份转移。

原生设置写入完成、网页确认整个导入成功后，检查本次恢复涉及的到访提醒、起售提醒和余票监控权限。缺失时保留已导入数据，展示受影响功能及进入权限管理的入口，不尝试代替用户授予权限。提示标记持久化，语言切换导致界面重建不会丢失；用户可以取消提示，稍后手动授权。

到访检测沿用权限不足时暂停并在恢复条件满足后继续的机制；余票监控配置恢复后保持停止；起售提醒不恢复一次性预约，系统权限不足时不能启动全屏闹钟。权限页新增全屏闹钟、精确闹钟及勿扰访问三项真实系统授权状态，点击打开相应系统设置，返回时刷新。
