# 车次开行日历

Android 原生 Compose 车次查询在“导出数据”和“车次线路图”之间显示开行日历。
使用现有 Material 3 Expressive 主题，按月份查看，边框标出本次查询的始发日期。
日历最大宽度为 1000 dp。可用宽度达到 600 dp 时，并排显示当前月份和下个月；
窄屏显示单月。月份按钮同时切换宽屏上的两个月。

数据由手机直接 POST 到官方接口：

```text
https://mobile.12306.cn/wxxcx/wechat/bigScreen/queryTrainDiagram
trainCode=G1
queryDate=20261024
```

`queryDate` 使用查询结果中的始发日期，避免表单编辑影响已显示的结果。
`running_list` 中 `flag=1` 显示绿色，`flag=0` 显示红色。
缺失日期、未知标记和相互冲突的记录保持中性色，不推断为停开。
接口返回的日历范围决定可切换的月份，不固定假设 91 天。
开行计划可能调整，不代表已经预售或保证实际开行。

请求与时刻表独立，取消页面任务时同时取消网络请求。
有效结果最多缓存 16 组，每组 15 分钟；失败、无有效日期或不支持的车次不缓存。
尚未取得有效日历、接口返回空数据或请求失败时，整个开行日历区块隐藏。
不在车次页面增加规则说明或错误提示。

## 验证

2026-10-24 验证记录：

- Android 单元测试 119 项通过，包含开行标记、非法日期、冲突记录、闰年和六周月份。
- Debug APK、设备测试 APK 构建和 `lintDebug` 通过，新增日历文件没有 lint 诊断。
- Pixel 8 Pro 与 Pixel Tablet 各通过 2 项设备测试，覆盖红绿状态、跨年切月、
  空日历隐藏、官方 G1 日历加载、导出按钮后的插入位置及宽屏双月同步切换。
- 已检查手机和平板截图，截图保存在本地 `build/verification/operating-calendar-*`。
