# 车次列表排序

本次同步原项目 `9d0d4eb` 中的车次列表规则；原项目当前提交为 `76657a8`。
同步日期：2026-10-24。

- 默认类别顺序为 G、D、C、S、Z、N、V、T、K、L、四位纯数字车次、Y。
- 其他类别置于末尾，五位纯数字车次沿用上游处理方式，归入其他类别。
- 同类别按首段车次数字排序，再按完整车次自然排序，保留双车次和方案后缀。
- 四位数字车次带方案后缀时仍归入纯数字类别。
- N、V 双车次的离线记录匹配继续支持省略后续字头，并保留日期筛选和精确记录优先。
- Android 原生列表沿用网页摘要的默认顺序；其他排序方式及升降序行为保持原状。

本次不导入上游更新日志、资料重组、发布脚本、workflow 及更新日志组件依赖。
车票和车次输入校验的未来规则未启用。
