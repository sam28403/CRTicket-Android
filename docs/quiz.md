# 每日小测验

车迷工具底部的“小测验”使用原生二级页面 `/railfan/quiz`。每日20题，按北京时间
切换日期，题目、答案、当前位置与完成状态保存到本机私有目录 `files/daily-quiz`。
答题过程中不显示规则说明、答对答错提示文字或考试功能。

## 每日题目和防重复

同一数据快照、同一北京时间日期使用相同的排序、语义标识、SHA-256种子及选项顺序，
不读取用户历史、设备标识或设备语言来决定题目。每个可用方向优先抽取两题。
整套题在第一次生成后原子写入，后续重新进入、进程重建或数据源变化均不改变当天题目。

语义标识分配到固定的32个日期槽，只有题目标识的槽与当天相符时才可入选。因此，
任意连续31天均不会出现相同的题目标识，跨月、跨年也适用；第32天以后允许再次入选。
四选一比较题的标识包含方向或指标及排序后的四个对象，交换选项顺序不会产生新题。
指定线路区间、相对方位、交路下一车次、担当及乘车题采用稳定的业务条件标识，
不把日期、数据版本或答案文本放入标识。以后更新生成器也必须保留这些语义约定。

不同应用版本可能内置不同数据快照。具体担当依赖上游当日记录和网络可达性，
有有效当日证据时才能入选；缺失的题位由其他方向补足。
因此相同快照的用户会尽量看到共同题目，无法保证所有网络条件下逐题完全相同。
如果要求跨版本、跨网络严格一致，需要另行提供统一发布的每日题包服务。

## 十个方向

| 方向 | 数据与判定 |
| --- | --- |
| 四站最北、南、西、东 | 从锚点60 km以内最近的12站中抽取干扰项，任意两站不超过120 km；保留唯一方位答案 |
| 四车次里程、历时、均速最大 | 当日计划开行且数据完整的车次；历时含跨日，均速为全程里程除以历时 |
| 四站今日办理车次最多、最少 | 按车站当天计数并去重；最高值不超过最低值的1.5倍，绝对差不超过30趟，排除并列答案 |
| 最接近指定里程、时长 | 里程目标100、500、1000、2000 km；时长目标1、2、5、10、12、20、24 h；排除等距答案 |
| 线路区间里程估算 | 同一线路的累计里程差，使用有唯一最近答案的估算选项 |
| 指定车站某个方向的车站 | 按纬度或经度比较，保证另外三站均在相反方向 |
| 指定线路上的车站 | 正确站属于该线路，另外三站均不在完整线路站表内 |
| 交路内下一车次 | 检查交路有效期、站点衔接、跨日日期及冲突；四个选项使用与正确答案相同的车次类型 |
| 今日担当车组号 | 复用rail.re车辆查询；只接受当日、对应车次且车组号唯一的记录，保留记录时间 |
| 当日可乘坐车次 | 出发站在目的站之前且满足当地出发日期；不限当天时刻；四个选项的首末站均不能是题目中的两站 |

“今日”时刻表题反映所用版本的计划，不验证临时停运或实际办理情况。
线路来源提供累计线路里程，并非官方客票计价数据库；第一版据此标注“线路里程”，
不宣称其等于官方计价里程，也不使用直线距离代替。乘车题不表示有余票或已经允许售票。

## 离线来源

`app/src/main/assets/quiz-sources.bin`是gzip压缩的统一内置快照，包含版本和原始时刻表SHA-256。
使用`.bin`扩展名，避免Android资源合并器自动解压并改变读取路径。

- 路路通公开时刻表及交路，复用项目已有解析器。当前版本20261030，共13411条车次、
  3560组交路。日期必须通过开行规则筛选，不能把缺少日期的记录当作每天开行。
- 原有OpenStreetMap坐标审计表与官方车站目录取交集，共3360站。
  坐标沿用原项目来源标注，© OpenStreetMap contributors，ODbL 1.0。
- 黄河铁路网现有线路查询来源，共22条线路，逐线路保留来源URL。
- 当日担当为可选联网补充；至多并行查询6个由日期确定的车次，总等待上限8秒。
  网络未通过连通性验证时直接跳过；保留超时前已获得的有效结果。
  历史记录、当日多个不同车组及无法获得三项不同干扰选项的记录均不出题。

题目刷新发生在设备内，正常离线答题不需要下载时刻表。数据内容随统一快照更新，
不是每天重新抓取整份时刻表。新模板提供中英文，其他语言暂使用英文题目模板。

更新快照：

```powershell
node tools/update-quiz-sources.mjs
# 也可指定已有的有效时刻表包：
node tools/update-quiz-sources.mjs --archive=build/research/llt-calendar/an.db
```

线路原始HTML缓存位于`build/quiz-sources`，构建与运行不联网执行这个维护脚本。
发布新快照时，应刷新线路HTML，并重新验证连续32天的题目。

## 答题交互

- 车站卡片复用`StationDiscoveryCard`，隐藏办理量、进度和路局等信息。
- 车次卡片复用`TrainListItem`，隐藏历时、里程、均速和停站数；
  交路下一车次题还隐藏始发、终到站。
- 答对后背景变绿，停留650毫秒后自动翻题。回看已答题不会再次自动翻题。
- 答错时所选项变红、正确项变绿，错误项左右摇动，并调用系统拒绝触觉反馈；
  系统振动设置或设备硬件可能影响反馈。
- 上下题切换有方向滑动与淡入淡出。可跳过未答题；第一题禁用上一题。
- 最后一题只有在全部题目都已作答时才可进入总结，显示“答对XX/XX题”与
  错误题目的正确答案陈述句。有未答题时留在最后一题，弹出
  “您还有x题未完成”的Toast；最后一题答对后的自动切换也遵守此限制。
- 旧版本已进入总结但仍有未答题的进度，会保留题目和已有答案，恢复到第一道未答题。
- 总结底部为“完成”，手机返回上一级，平板打开生成车票页面。
  当天完成后重新打开直接显示总结。
- 总结以环形成绩卡和20题结果色块展示成绩。手机上下排列成绩与错题答案，
  可用宽度达到700dp时采用双栏，成绩和错题列表分别占据两侧；仅一道错题时增加答案卡高度。
  全对时成绩卡填满内容区，并显示奖杯图标与“全部答对”，不留下空的错题列表。
- 全部题目答对后播放有限时长的Konfetti礼花，约4秒后卸载动画，不拦截按钮操作。
  系统关闭动画时只显示静态成绩卡。重新进入当前总结可以再次庆祝，单次停留不会循环播放。
- 仅CI版本在总结页“完成”上方提供“重置题目”按钮，弹窗选择“重答同一组”或
  “换一组题”，也可取消。两种操作都清空答案、答题时间和完成状态，回到第一题。
  同组保留原题组和换组历史；换组使用当前数据快照及原答题日期重新选20题，
  使用独立随机种子，排除当天已出现的所有题目，并保存替换后的题组。
  车站、车次和具体车组的选项组合若有至少3项与历史题相同，也视为高度相似而排除；
  同一新题组内部同样检查，数字里程选项不因数值相近而排除。
  CI手动换组用于测试，不属于正式版每日共同题组的保证范围。
  正式版不提供该入口。重置后退出再进入也从重置后的进度继续。
- 换组准备时显示加载状态，成功后立即在原页面进入新题组第1题。
  切页内容按日期和题组隔离，不沿用旧总结的动画状态，无需退出再进入。
- 换组历史采用语义标识和选项组合的紧凑指纹，随当天进度原子保存，重启后仍有效。
  各题型在应用候选数量上限前先跳过历史题，从底层数据继续寻找新候选，避免只在
  固定的前几个候选之间循环。旧进度首次使用新版换组时从当前题组开始记录。
  有效新候选不足20题时保留原题组，不静默清空历史或复用旧题；跨日使用新的每日记录。
- 每张错题陈述卡片右上角提供红色报告图标，进入三级页面
  `/railfan/quiz/report?date=...&question=...`。返回后仍为当天总结。
- 报告页读取对应日期已保存的题目、四个选项、参考答案与陈述句、用户答案和答题时间。
  只有已完成小测验中的错误答案可以报告；无效链接不会创建或替换题库。
- 理由为必填，填写后可打开项目Issues的预填表单，由用户在GitHub确认提交。
  复制题目会包含完整的五项模板，未填理由时保留填写占位符。
  内容超过URL长度阈值时复制完整内容并打开仅预填标题的表单，不截断理由。
- 新答案保存实际答题时间，按北京时间展示；旧进度缺少精确时刻时明确标为未记录，
  不以打开报告页的当前时间或当天零点代替。
- 北京时间跨日后加载新题；页面离开时停止自动翻题与日期检查。
- 当天进度保存在本机，不参与现有备份格式，也不跨设备同步。
