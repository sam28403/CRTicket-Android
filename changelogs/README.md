# 更新日志维护

日志使用 Markdown 编写，更新页渲染标题、列表、粗体、斜体、链接、引用、代码、分隔线、删除线和表格。图片暂不加载。正文颜色适配系统深浅主题。

仅在升级版本号时撰写更新日志：每次将版本升级至 x.x.x 时，同时新增 `changelogs/x.x.x.md`，核对上一个版本以来的全部改动，填写该版本实际更新内容。日常开发不新增或持续改写版本更新日志；已发布的旧版本日志保持不变。版本号由 `gradle.properties` 的 `crticket.version` 管理。

Android 构建将此目录打包为 assets/changelogs，更新欢迎页按语义版本读取同名文件。Git 哈希变化不会重复弹出欢迎页。首次安装先显示欢迎与使用条款；同意后记录条款版本和当前版本。已有安装首次接入本机制时，也需要阅读并同意条款。

条款页要求滚动到底部才能同意；软件只能确认到达文末，无法判断用户是否实际理解全文。不同意或在欢迎流程返回会退出，且不会保存同意状态。今后条款有实质变化时，应提高 WelcomeState 中的 TERMS_VERSION。

首版欢迎页新增文案提供简体中文和英文；其他语言暂使用英文文案，繁体中文目录的新增文案暂沿用简体中文。后续翻译仍统一放在各语言目录的 strings.xml。
