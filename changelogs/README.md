# 更新日志维护

日志使用 Markdown 编写，更新页渲染标题、列表、粗体、斜体、链接、引用、代码、分隔线、删除线和表格。图片暂不加载。正文颜色适配系统深浅主题。

每次完成改动后，主动将实际更新内容写入对应版本的 `changelogs/x.x.x.md`，无需等待额外提醒。版本号由 `gradle.properties` 的 `crticket.version` 管理，不为日常改动单独升级版本或创建临时开发日志。升级版本时新增对应文件，并核对上一个版本以来的全部改动。已发布的旧版本日志保持不变，后续改动写入当前开发版本。

Android 构建将此目录打包为 assets/changelogs，更新欢迎页仍按语义版本读取同名文件。是否展示更新欢迎页以 Android 版本数值 versionCode 为准。版本数值与上次完成欢迎流程时记录的数值不同时，下次启动展示更新完成界面；完成后记录当前版本数值，同一数值不重复展示。升级和降级都适用。旧安装没有版本数值记录时展示一次更新欢迎。首次安装先显示欢迎与使用条款；同意后记录条款版本和当前版本数值。已有安装首次接入本机制时，也需要阅读并同意条款。

条款页要求滚动到底部才能同意；软件只能确认到达文末，无法判断用户是否实际理解全文。不同意或在欢迎流程返回会退出，且不会保存同意状态。今后条款有实质变化时，应提高 WelcomeState 中的 TERMS_VERSION。

首版欢迎页新增文案提供简体中文和英文；其他语言暂使用英文文案，繁体中文目录的新增文案暂沿用简体中文。后续翻译仍统一放在各语言目录的 strings.xml。
