# 0.9.5

欢迎体验 **Sam-Lab CRTicket 0.9.5**。以下为相较 0.9.4 新增和修改的内容。

## 新增

- 车迷工具新增普速票价计算，按车次、里程和空调类型展示七种席别的参考票价；计算后切换空调类型即可即时更新结果。
- 新增完整里程与价格表，覆盖 1 至 5000 公里，支持下拉选择计价等级和空调类型，全部行在一页内滚动浏览，提供车次列表同款快速滑动条。
- 设置新增“更新”分组，支持手动检查 GitHub 新版本、使用预览版和启动时自动检查更新。预览版默认关闭，自动检查默认开启；无更新时，手动检查显示提示，自动检查保持静默。
- 发现新版本后展示最新版 Markdown 更新日志，提供“下载更新”和“稍后更新”。更新包通过系统下载管理器下载，显示进度和完成通知，并可交由系统安装器确认安装。
- “使用预览版”和“自动检查更新”支持随“设置项”备份导出、导入，恢复后立即同步界面；未选择设置项或旧备份缺少对应字段时，保留当前选择。

## 优化

- 搜索结果新增快速滑动条。从搜索结果进入详情后返回，保留关键词、分组展开状态和滚动位置，不重新加载已有结果。
- 车次列表、车站大屏、下一交路预览、车组历史及搜索结果进入车次查询时，统一优先在线查询，不可用时回退离线，并保留完整离线记录号。
- 普速票价计算采用同排输入及自适应票价卡片，手机显示两列，宽屏显示更多列；完整表按列宽简化表头并调整金额字号。
- 关于页及问题报告链接改为独立的 [CRTicket-Android 仓库](https://github.com/sam28403/CRTicket-Android)。
- 更新提示页保持欢迎页的界面风格，手机端缩小操作按钮间距，平板端将两个按钮并排展示。
- 安装更新前检查安装来源授权，拒绝或返回时安全退出安装流程，并支持授权变化后的进程恢复；直接调用系统安装器，避免进入第三方 APK 工具的打开方式选择器。

## 维护

- 同步原项目 261025 的普速票价算法和对应测试，补充计价模型、来源与适用范围说明。
- CI 构建禁用更新设置及检查、下载和安装入口，避免使用正式版更新渠道；备份仅迁移更新开关，不迁移下载任务、文件或系统授权。
