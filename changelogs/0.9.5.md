# 0.9.5

欢迎体验 **Sam-Lab CRTicket 0.9.5**。以下为相较 0.9.4 新增和修改的内容。

## 新增

- 车迷工具底部新增每日小测验，按北京时间每天提供20道四选一题目，支持离线答题；同一数据版本按日期共同选题，任意连续31天内题目不重复。
- 小测验涵盖车站方位、车次里程与历时、均速、车站办理量、线路里程与归属、下一交路、当日担当车组及当日乘车判断；缺少可靠当日担当记录时以其他题型补足。
- 小测验保存当天题目和答题进度，结束后展示答对题数及错题的正确答案陈述句，当天再次进入直接显示总结。
- 错题陈述卡片提供红色报告图标，进入独立三级页面后可填写理由、复制完整题目模板或打开项目 Issues 预填表单；自动带入参考答案、用户答案与答题时间，并兼容时间未记录的旧进度。
- 车迷工具新增线路查询，接入数据源完整的 759 条线路目录，输入线路名称即可在下拉菜单选择候选，查看沿线站点与累计里程，支持目录更新及已查询线路缓存。
- 首页搜索支持按名称匹配铁路线路，例如输入“沪昆”可显示沪昆线、沪昆高速线，点击结果直接查看对应线路的站点与里程。
- 线路搜索结果合并为一张分组卡片，保留展开、收起和独立点击；线路查询入口及搜索结果统一使用 Material 铁路图标。
- 车迷工具新增普速票价计算，按车次、里程和空调类型展示七种席别的参考票价；计算后切换空调类型即可即时更新结果。
- 新增完整里程与价格表，覆盖 1 至 5000 公里，支持下拉选择计价等级和空调类型，全部行在一页内滚动浏览，提供车次列表同款快速滑动条。
- 设置新增“更新”分组，支持手动检查 GitHub 新版本、使用预览版和启动时自动检查更新。预览版默认关闭，自动检查默认开启；无更新时，手动检查显示提示，自动检查保持静默。
- 发现新版本后展示最新版 Markdown 更新日志，提供“下载更新”和“稍后更新”。更新包通过系统下载管理器下载，显示进度和完成通知，并可交由系统安装器确认安装。
- “使用预览版”和“自动检查更新”支持随“设置项”备份导出、导入，恢复后立即同步界面；未选择设置项或旧备份缺少对应字段时，保留当前选择。
- 首次启动在欢迎页和使用条款之后增加导入备份提示，支持选择手机版或网页版的 JSON 备份并按需恢复，也可跳过后进入首页。
- 备份导出默认启用密码加密，支持通过备份文件和密码在其他设备恢复；手机版与网页版使用相同的加密格式，并继续兼容旧版明文备份。
- 车次查询右上角新增刷新按钮，仅在线模式显示，支持刷新当前展示车次的正晚点；刷新期间保留已有结果，并禁用按钮以避免重复请求。

## 优化

- 小测验须全部作答后才能查看总结，未完成时提示剩余题数；旧版跳过题目却已结算的进度恢复到首道未答题。CI 版本总结页在“完成”上方增加“重置题目”，弹窗选择重答同一组或换一组题，清空答案与答题时间，方便重新测试；换组排除上一组全部题目。
- 欢迎页、使用条款、备份导入提示及更新说明切换时，使用与小测验相同的双向滑动和淡入淡出动画，返回时反向播放。
- 小测验答对后自动进入下一题，答错时所选项变红、参考答案变绿，并提供摇动与系统震动反馈；切题保留方向动画，平板总结页完成后打开生成车票页面。
- 小测验方位题采用同一区域的邻近车站，办理量题限制选项数量差距，交路题统一选项车次类型，乘车题使用中途站且不限制当日出发时刻；车次和车站卡片隐藏会泄露答案的统计信息。
- 错题报告图标独立排列在卡片右侧，保持题号与陈述文字的间距，避免按钮撑高题号行或遮挡正文。
- 帮助中心补充每日小测验、题目报告、线路查询与普速票价说明，更新加密备份和正晚点缓存、列车追踪的数据口径。
- 地图选择器参照语言设置整理分组：“自动选择”保持独立，其余候选地图源合并为连续的圆角组。
- 线路查询使用双线圆点线路图，增大站名和里程字号，里程与 km 保持单行；大屏按可用宽度自动采用蛇形布局，逐行折返连接站点。
- 线路名称与起终点合并在同一行，起终点在右侧显示，为站点图腾出更多空间。
- 线路名称和起终点在空间不足时自动缩小字号，保持单行完整显示，避免省略号截断。
- 车迷工具依次排列为车辆查询、交路查询、线路查询、到访车站统计、普速票价计算、车速表和小测验。
- 搜索结果新增快速滑动条。从搜索结果进入详情后返回，保留关键词、分组展开状态和滚动位置，不重新加载已有结果。
- 车次列表、车站大屏、下一交路预览、车组历史及搜索结果进入车次查询时，统一优先在线查询，不可用时回退离线，并保留完整离线记录号。
- 车站大屏根据路路通分段车次和换号里程显示本站实际车次，例如南京南显示 G100；换号站的到达屏和出发屏分别使用到达、出发车次，缺少可靠分段数据时保留完整车次。
- 修复从车站大屏进入详情后车次变为整趟列车首车次的问题，例如上海南点击 G3244 后，查询框和详情标题继续显示 G3244；切换在线、离线来源时保留所选车次，并关联完整离线记录。
- 普速票价计算采用同排输入及自适应票价卡片，手机显示两列，宽屏显示更多列；完整表按列宽简化表头并调整金额字号。
- 关于页及问题报告链接改为独立的 [CRTicket-Android 仓库](https://github.com/sam28403/CRTicket-Android)。
- 更新提示页保持欢迎页的界面风格，手机端缩小操作按钮间距，平板端将两个按钮并排展示。
- 安装更新前检查安装来源授权，拒绝或返回时安全退出安装流程，并支持授权变化后的进程恢复；直接调用系统安装器，避免进入第三方 APK 工具的打开方式选择器。
- 导入加密备份时先校验密码与文件完整性，再选择恢复内容；密码错误或文件被篡改时不写入数据，修复较大备份解密后可能一直等待的问题。
- 恢复备份时按本机实际权限处理到站检测和起售闹钟开关，权限不足时保持关闭，其他资料和记录仍可正常恢复；后续补齐权限后由用户手动开启。
- 车次查询和车站大屏保留当天已有的正晚点缓存，刷新失败、超时、空结果或部分字段缺失时不再清除对应修正；有效新数据逐项更新，缓存于北京时间午夜清除。
- 车次正晚点刷新失败且已有当天缓存时，保持开关开启并继续定期重试；车站列表重新加载及分批刷新时继续复用对应到发时刻的缓存。
- 修复单侧晚点较大、后续站缺少有效正晚点数据时，列车追踪可能跳过运行区间或提前显示终到的问题；时刻冲突时按原定停站及区间运行时长推算后续事件，支持跨午夜处理，后续有效预测仍可反映追回的晚点。

## 维护

- 为每日小测验打包统一离线数据快照，补充日期确定性、跨月防重复、跨日服务、干扰项约束和旧进度时间字段兼容测试。
- 欢迎页和小测验共用切页动画组件，补充前进与返回动画、条款阅读限制、备份提示及新增帮助主题的导航回归检查。
- 同步原项目 261025 的普速票价算法和对应测试，补充计价模型、来源与适用范围说明。
- CI 构建禁用更新设置及检查、下载和安装入口，避免使用正式版更新渠道；备份仅迁移更新开关，不迁移下载任务、文件或系统授权。
- 补充备份加密、跨设备格式兼容、大文件恢复及权限处理回归检查，以及正晚点缓存合并、午夜失效和手机刷新场景测试。
- 补充分段车次解析、换号站到发显示和详情入口回归检查，并在 Pixel 8 Pro 与 Pixel Tablet 上验证真实数据、标签切换、刷新及在线、离线来源切换。
- 补充单侧晚点、后续站数据缺失、跨午夜及在线刷新回归检查；在 Pixel 8 Pro 与 Pixel Tablet 上使用可控数据验证刷新按钮、缓存保留和原生追踪通知，两台设备各通过 4 项真机测试。
