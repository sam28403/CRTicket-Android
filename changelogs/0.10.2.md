# 0.10.2

欢迎体验 **Sam-Lab CRTicket 0.10.2**。以下为相较 0.10.1 修改的内容。

## 优化

- 车辆查询支持按查询层级逐层返回，先恢复上一个车号或车次结果，再回到车辆搜索页和首页；保留已有结果与列表位置，刷新不增加返回层级。
- 加快下关站照片加载：完整车号优先精确检索，照片与历史记录并行加载；照片对应关系和拍摄信息在本地缓存 24 小时，再次查看不等待网络，并随照片缓存统一清理。

- 车辆实拍照片新增本地缓存，可在清理存储中单独或随全部清理删除；大屏改为左侧照片、右侧直接展示拍摄信息和出处，限制图片高度，手机保留点击详情。

- 车辆查询新增下关站实拍照片，支持完整车号及唯一简称匹配；无历史记录但有照片时仍展示，匹配不唯一或图片加载失败时隐藏。点击照片可查看出处、作者与拍摄信息，未知车次显示“未知”；关于页致谢加入下关站。

- 修复从系统存储管理入口冷启动时设置页一闪而过的问题，直接显示清理存储页，数据层就绪后再读取占用。

- 系统应用信息中的存储管理入口改为打开应用内清理存储页面，支持按分类管理数据，进入页面不会直接删除全部数据。

- CI 开屏动画和首页产品图标同步为橙色 CI 票面；各语言的应用名称、欢迎页、权限说明、分享、导出和错误报告统一使用 CRTicket CI，应用内更新说明同步显示 CI 名称。
- CI 版本采用独立的橙色 CI 票面启动图标，并提供镂空 CI 字形的 monochrome 图标，在系统主题图标模式下也可与正式版区分。
- 起售时间查询中，搜索的目标车站卡片使用系统主题强调色背景，并适配文字颜色；同城其他车站保持普通背景，便于区分查询目标。
- 起售提醒铃铛按钮按系统主题成对设置背景与图标颜色，已订阅状态使用主色，禁用状态保持清晰对比，修复强调背景下图标难以辨认的问题。

- 清理存储新增错误日志分类，可查看占用、单独清理或随全部清理删除设备上的异常报告。

- 新增独立进程异常报告页，展示设备与堆栈信息，支持复制及重启；捕获未处理异常及前台主线程长时间无响应。

- CI 版本隐藏设置中的整个更新模块，并从首页搜索移除更新设置入口。

- 从首页搜索打开结果或设置编辑弹窗时，自动清除搜索框焦点并收起键盘。

- 首页全局搜索统一车辆查询输入规则，支持纯数字车辆编号（如 5033），与车次结果同时展示；车辆记录支持展开全部，补充交路结果及铁道迷功能入口，各类查询独立加载。车辆查询仅在实际返回记录时显示，文字、空结果及失败不显示车辆区域。

- 补齐首页搜索中的更新、铁道迷工具、地图、存储及各设置子页内容，支持检索全部帮助主题的标题、问题和正文，并提供对应页面入口。

- 修复小测验乘车题换组后正确答案反复集中于少数车次的问题，车次、中途站区间和干扰项随换题种子重新打乱，同一组及连续换组避免重复使用已作正确答案的车次。

- 小测验车站限定为内置客运时刻表有效期内至少有一天有列车办客的站点，排除仅存在于车站目录的非营运站，保留马海、额济纳等非每日开行站；已保存题目中的不合格站点题会自动替换。

- 修复车站大屏和交路查询退出后重新进入时，输入框仍保留上次查询内容的问题；从车次详情返回时继续保留当前查询，从指定车站链接进入大屏时仍显示对应站名。
- 优化帮助详情页标题，减小字号并支持自动换行与高度自适应，避免长标题在较大显示比例下显示不全；继续遵循系统字体缩放。
- 修复帮助详情页更换标题栏后正文无法正常滑动的问题，恢复长内容滚动，并按标题下方的可用高度展示正文，确保页尾可浏览。

## 维护

- Pixel 8 Pro 的 CI 包通过逐层查询返回和照片加载两项设备测试，覆盖 C3896、CRH2A-2001、2001 的返回顺序；新增精确检索单元测试，本次首次加载 9622 ms、本地缓存读取 61 ms，缓存清理检查继续通过。

- 真实 Pixel Tablet 验证照片与拍摄信息左右布局、缓存统计及清理前请求不可写回；Pixel 8 Pro 通过照片交互与清理存储回归，覆盖取消、单项清理、全部清理和个人数据保留。未调整设备显示参数。

- 车辆实拍照片新增四项解析及唯一匹配单元测试；Pixel 8 Pro 的 CI 包通过真实 HTTP 图片、无历史记录、唯一简称、歧义车号及详情弹窗验证，并检查照片位置与弹窗截图。

- 移除 Android 项目中不再使用的 GitHub 动图文件及其引用，精简安装包，保留全部现有字体。

- 移除停用的更新专用测试构建、固定旧版更新入口及其专用真机测试，同步更新验证文档。

- CI 品牌资源生成兼容 Gradle 配置缓存；正式 debug 包构建通过，Pixel 8 Pro 通过品牌与图标两项测试，覆盖全部 26 种语言的主要品牌文案、原仓库链接保留、更新说明及启动动画资源。
- 在 Pixel 8 Pro 安装 CI 包并通过启动图标资源测试，检查自适应图标、monochrome 透明字形及预览效果；独立图标资源仅放入 CI 构建目录。
- 在 Pixel 8 Pro 的 CI 版本通过铃铛对比度与起售查询两项测试；浅色、深色主题分别检查可用、已订阅、禁用状态的实际渲染颜色，当前系统配色下图标与按钮背景对比度均超过 6:1，并核对深色主题截图。

- 在 Pixel 8 Pro 的 CI 版本通过起售时间查询回归测试，验证目标站与同城其他站的卡片背景区分、系统主题强调色匹配、关闭同城查询后强调背景保留，以及输入校验与历史记录操作，并检查结果截图。

- 补充查询输入清空回归测试，并在 Pixel 8 Pro 和 Pixel Tablet 上通过输入清空、交路结果显示及车站输入编辑测试，每台设备 3 项，共 6 项。
- 补充帮助标题回归测试，在 Pixel 8 Pro 和 Pixel Tablet 当前显示设置下通过全部 11 个帮助主题的标题完整性检查，并检查页面截图；第三台设备测试进程异常退出，未计为通过。验证未调整设备显示参数。
- 补充帮助正文回归测试，遍历全部 11 个主题，检查长正文可通过手势滚动、页尾完整可见；Pixel 8 Pro 和 Pixel Tablet 均通过标题及正文两项测试。平板当前可完整容纳的正文直接验证页尾可见性，未调整设备显示参数。
