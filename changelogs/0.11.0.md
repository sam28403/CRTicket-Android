# 0.11.0

欢迎体验 **Sam-Lab CRTicket 0.11.0**。以下为相较 0.10.3 修改的内容。

## 重要提醒

如果应用内下载失败，可前往 [CRTicket Android 发布页](https://github.com/sam28403/CRTicket-Android/releases/latest) 手动下载安装包。

- `CRTicket-v0.11.0.apk` 为普通版，首次使用路路通离线查询需要联网下载时刻表。
- `CRTicket-v0.11.0-offline.apk` 内置路路通时刻表，可直接使用离线查询。
- `CRTicket-v0.11.0.apks` 为分包安装文件，可使用支持 APKS 的安装器安装。

## 更新

- 新增中老铁路老挝段在线与离线时刻。同号车次可切换线路，适用车次可选择当地时间、北京时间或万象时间。
- 老挝段车站大屏按万象时间显示和筛选车次。车次时刻 PDF 使用当前所选时区，并标明跨日。
- 老挝段车次详情显示开行日历，离线查询选到停运日仍可查看。
- 帮助中心补充离线查询、中老铁路时区、开行日历和新旧车次对比，并更新小测验说明。

## 优化

- 在新旧车次对比列表加入快速滑动条。
- 车票 PDF 按 86 × 54 毫米票面尺寸导出。
- 应用内更新在普通版与离线版同时提供时优先下载普通版。

## 维护

- 更新离线安装包内置的路路通时刻表。打包时选用仓库中版本号最高的有效快照。
- 升级 Gradle、Android Gradle Plugin 和相关依赖。
- 增加路路通数据包的条目数、重复文件和解压大小检查。
