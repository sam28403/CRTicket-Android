# 0.9.4

欢迎体验 **Sam-Lab CRTicket 0.9.4**。以下为从 0.9.2 升级后的更新内容。

## 新增

- 首次使用欢迎界面，展示应用图标、Sam-Lab 工作室图标和 Expressive 形状动画。
- 欢迎页展示车票生成、车次查询、余票监控和运转数据四项特色功能，副标题为“您的中国铁路旅行伴侣”。
- 使用条款说明开源免费、生成车票不能用于实际乘车、小地图仅覆盖中国铁路运营区域，以及权限用途、数据与第三方服务、使用责任。
- 条款必须滚动至末尾才能同意并进入应用；不同意则退出，且不记录同意状态。
- 更新后展示“感谢您使用”和当前版本号，下一页显示该版本的更新日志。
- 更新日志按语义版本记录阅读状态，同一版本不重复显示，Git 提交哈希变化不会再次触发欢迎流程。
- 同步原项目，测试N、V车次加入后系统稳定性。

## 优化

- “欢迎使用”和“感谢您使用”均与下一行的应用名称分开显示，标题使用 Google Sans Rounded 字体。
- 更新日志支持 Markdown 标题、列表、粗体、斜体、链接、引用、代码、分隔线、删除线和表格，正文适配深浅主题。
- 报告错误预览使用同一套 Markdown 排版，保留文本选择、复制报告和 GitHub 提交功能；复制与提交仍使用原始 Markdown 内容。
- 可选设备信息新增 GMS 版本、当前 WebView 提供程序名称和版本，包含版本代码；无法获取时显示不可用状态。
- 设备机型、Android、GMS 和 WebView 信息分别换行显示，避免 Markdown 将多项信息合并成一段。
- 车次、车号输入框默认大写，修复部分空状态缺失的问题。

## 维护

- 新增项目内的 `changelogs` 目录，构建时打包版本日志，更新界面按当前版本读取对应的 Markdown 文件。
- 新增欢迎页中文与英文文案，其他语言暂使用英文，繁体中文目录的新增欢迎文案暂沿用简体中文。
- 新增更新欢迎、Markdown 渲染和设备信息采集的定向设备测试，并适配错误报告流程测试。
- 修复`okhttp`至`5.5.1`。
